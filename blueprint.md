
# Blueprint

## Overview

This is a personal portfolio website for Mathys Johannes Van Heerden. It showcases his skills, projects, and contact information. The website is built with HTML, CSS, and JavaScript, and it is hosted on Firebase.

## Project Structure

*   `index.html`: The main HTML file.
*   `style.css`: The main CSS file.
*   `main.js`: The main JavaScript file.
*   `assets/`: A directory for storing assets like images and documents.
*   `firebase-config.js`: Firebase configuration file.
*   `view-counter.js`: Web component for the view counter.
